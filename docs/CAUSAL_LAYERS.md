# 时序因果七层结构

> 本文档详细描述主体间关系代数中的时序因果层级体系。

## 1. 概述

时序因果七层结构（Temporal Causal Layers）描述了从瞬时感知到长期记忆的完整认知流程，共分为七个层次。

## 3. 各层详细说明

### 第一层：事件层（Event Layer）

**功能**：原始事件的接收和初步记录

**数据结构**：
```python
EventLayerRecord:
    raw_event: RawEvent           # 原始事件对象
    timestamp: float              # Unix 时间戳
    source_pod_id: str           # 源隔离舱
    initial_channels: Set[PerceptionChannel]  # 初始通道
```

**处理规则**：
1. 记录事件发生的时间
2. 标记事件来源
3. 初步分配感知通道

### 第二层：感知层（Perception Layer）

**功能**：将原始事件转换为感知事件

**处理规则**：
```python
PerceptionLayer:
    def process(raw_event):
        perception_event = PerceptionEvent(
            source_pod=raw_event.source_pod_id,
            description=raw_event.description,
            channels=infer_channels(raw_event),
            content=raw_event.content,
        )
        # 分发给可观测的隔离舱
        return perception_event
```

**通道推断**：
- 基于事件描述的关键词匹配
- 基于内容类型的默认通道
- 基于上下文的通道扩展

### 第三层：关联层（Association Layer）

**功能**：建立记忆点之间的关联

**关联强度计算**：
```python
ConnectionStrength:
    channel_overlap: float   # 通道重叠度 (权重 0.4)
    temporal_proximity: float  # 时间邻近度 (权重 0.2)
    spatial_proximity: float   # 空间邻近度 (权重 0.2)
    emotional_similarity: float  # 情感相似度 (权重 0.2)
    
    total = (channel * 0.4 + temporal * 0.2 +
             spatial * 0.2 + emotional * 0.2)
```

**关联规则**：
- Jaccard 相似度计算通道重叠
- 指数衰减计算时间邻近（1小时为基准）
- 欧氏距离计算空间邻近
- 情感效价差异计算情感相似

### 第四层：推理层（Reasoning Layer）

**功能**：基于关联进行推理

**推理类型**：
```python
class ReasoningType(Enum):
    DEDUCTION = "演绎推理"      # 从一般到特殊
    ABDUCTION = "溯因推理"      # 从结果到原因
    ANALOGY = "类比推理"        # 从相似到相似
    CAUSATION = "因果推理"      # 因果链追溯
```

**因果链结构**：
```
Cause_1 ──► Effect_1 ──► Intermediate_Effect ──► Final_Effect
   │              │                              │
   └──► 因果权重 ──┴──► 因果强度 ───────────────┘
```

### 第五层：决策层（Decision Layer）

**功能**：基于推理结果做出决策

**决策过程**：
```python
DecisionProcess:
    1. 收集候选方案
    2. 评估每个方案的结果
    3. 计算预期效用
    4. 选择最优方案
    5. 形成执行意图
```

**决策因素**：
- 记忆强度（越强的记忆影响越大）
- 情感效价（正面情感倾向行动）
- 社会因素（考虑其他主体）
- 时效性（紧急程度）

### 第六层：整合层（Integration Layer）

**功能**：整合多源信息形成统一认知

**整合过程**：
```python
IntegrationProcess:
    1. 多通道信息融合
    2. 跨模态关联
    3. 情境更新
    4. 一致性维护
```

**情境模型**：
```python
ContextModel:
    time_slice: TimeSlice      # 当前时间切片
    space_slice: SpaceSlice    # 当前空间切片
    active_pods: Set[str]      # 活跃的隔离舱
    recent_events: List[Event] # 最近事件
    emotional_state: float     # 情感状态
```

### 第七层：元认知层（Meta-Cognition Layer）

**功能**：对认知过程的监控和调整

**元认知能力**：
```python
MetaCognition:
    monitoring:        # 监控
        - 当前认知状态
        - 推理过程
        - 决策质量
    
    evaluation:       # 评估
        - 准确性检查
        - 一致性验证
        - 效率评估
    
    regulation:       # 调节
        - 注意力分配
        - 策略调整
        - 目标更新
```

**跨时间一致性**：
```python
TemporalConsistency:
    """
    维护跨时间的自我同一性
    - 核心价值观稳定性
    - 人格特质一致性
    - 记忆连贯性
    """
```

## 4. 层间交互

### 4.1 向下因果（Downward Causation）

```
元认知层 ──► 决策层 ──► 推理层 ──► 关联层 ──► 感知层 ──► 事件层
   │                                           │
   └──► 注意力调节 ─────────────────────────────┘
```

### 4.2 向上因果（Upward Causation）

```
事件层 ──► 感知层 ──► 关联层 ──► 推理层 ──► 决策层 ──► 整合层 ──► 元认知层
                                                                        │
   ◄────────────────────────────────────── 新认知形成 ──────────────────┘
```

## 5. 时间尺度

| 层次 | 时间尺度 | 示例 |
|------|----------|------|
| 事件层 | 毫秒 | 100ms 内的感知输入 |
| 感知层 | 毫秒-秒 | 1秒内完成感知转换 |
| 关联层 | 秒-分钟 | 几分钟内建立关联 |
| 推理层 | 秒-分钟 | 几分钟的推理过程 |
| 决策层 | 秒-分钟 | 快速决策或深思熟虑 |
| 整合层 | 分钟 | 10-30分钟的整合 |
| 元认知层 | 分钟-小时+ | 长期自我监控 |

### 6.2 因果权重

```python
CausalWeight:
    """
    因果边的权重计算
    
    W = 强度 × 频率 × 时序邻近度
    """
    intensity: float      # 因果强度
    frequency: float      # 出现频率
    recency: float        # 时序邻近
    
    weight = intensity * frequency * recency
```
