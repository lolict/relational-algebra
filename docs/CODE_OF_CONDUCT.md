# 行为准则

## 我们的承诺

为了营造一个开放、包容、无骚扰的项目社区，我们承诺无论年龄、体型、肤色、残疾、经验水平、教育程度、社会地位、国籍、个人外貌、种族、宗教或性取向如何，都要让所有参与者有一个无骚扰的体验。

## 我们的标准

### 积极行为

- 使用欢迎和包容的语言
- 尊重不同的观点和经验
- 优雅地接受建设性批评
- 关注对社区最有利的事情
- 对其他社区成员表示同理心

### 不可接受的行为

- 使用带有性暗示的语言或图像，以及不受欢迎的性关注
- 挑衅、侮辱/贬损评论，以及人身或政治攻击
- 公开骚扰或私人骚扰
- 未经明确许可发布他人的私人信息
- 其他可以被合理地认为不适当的专业环境

## 我们的责任

项目维护者有责任明确可接受行为的标准，并对任何不可接受行为的情况作出适当和公平的反应。

项目维护者有权和责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、wiki 编辑、问题和其他贡献，或暂时或永久禁止任何贡献者的行为，他们认为不适当、有威胁、冒犯或有害的其他行为。

## 适用范围

本行为准则适用于所有项目空间，也适用于个人在公共空间代表项目或社区的情况。

## 执法

可以通过向项目维护者发送邮件来报告滥用、骚扰或其他不可接受的行为。

所有投诉都将经过审查和调查，并将根据具体情况作出必要的回应。项目维护者有义务对事件举报人保密。

## 执行指南

对于项目维护者违反本行为准则的行为，将受到以下影响：

1. **警告**：口头或书面警告，解释违规原因
2. **暂时禁止**：在指定时期内禁止参与项目活动
3. **永久禁止**：永久禁止参与项目活动

## 归属

本行为准则改编自 [Contributor Covenant](https://www.contributor-covenant.org/)，版本 2.0。
